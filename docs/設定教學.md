# 第 6 步設定教學：Google 登入、Google Sheets 成績記錄、老師控制台

全程大約 30 分鐘。跟次序做，每一部分做完先做下一部分。

> Google 的設定頁面經常改版，按鈕名稱或位置可能與下面略有不同（例如「OAuth 同意畫面」新版叫「Google Auth Platform」）。找不到時，用頁面頂部的搜尋列搜尋相同字眼。

## 你需要

- 老師的**學校 Google 帳戶**（用來建立試算表及 Google Cloud 專案）
- GitHub 帳戶（遊戲已放在 `wychankelly-hub/taxi-python-game`）
- 一位學生的學校帳戶（第 6 部分測試用）

## 整體流程

```
學生 iPhone ──「用 Google 登入」──► Google 發出 ID 權杖
      │
      └─► Apps Script（你的試算表內）── 向 Google 驗證權杖 ──► 取得電郵 ──► 學生名單
                │
                └─► 寫入 關卡紀錄／錯誤紀錄／考試成績 → 總覽自動計算
老師 ── teacher.html ──「用 Google 登入」──► Apps Script（只限「設定」內的老師）
```

## 第 1 部分：用 GitHub Pages 發佈遊戲

遊戲已上載到 https://github.com/wychankelly-hub/taxi-python-game 。每次更新 `main`，GitHub 會自動：先跑全部自動測試 → 通過才發佈（設定在 `.github/workflows/pages.yml`）。

1. 打開 repository → **Settings** → 左邊 **Pages**。
2. **Build and deployment** → **Source** 揀「**GitHub Actions**」（不是 Deploy from a branch）。
3. 到 **Actions** 分頁，等「測試及發佈到 GitHub Pages」出現綠色剔號（約一兩分鐘）。如果未自動開始，揀這個工作流程 → **Run workflow**。
4. 遊戲網址：**`https://wychankelly-hub.github.io/taxi-python-game/`**。下面稱為「**遊戲網址**」。
5. 用 iPhone 打開遊戲網址，確認遊戲可以玩。這時還未有登入按鈕，是正常的。

> GitHub Pages 對公開 repository 免費。如果把 repository 改為私人，免費帳戶便不能用 Pages。

## 第 2 部分：建立成績試算表及 Apps Script

1. 打開 [Google 雲端硬碟](https://drive.google.com)（用學校帳戶）→ **新增** → **Google 試算表** → 命名為「的士佬日記成績」。
2. 在試算表上方選單：**擴充功能** → **Apps Script**。
3. 左邊 `程式碼.gs`：刪除原有內容，貼上本專案 `apps-script/Code.gs` 的全部內容，按 💾 儲存。
4. 左邊齒輪 **專案設定** → 勾選「**在編輯器中顯示『appsscript.json』資訊清單檔案**」。
   回到編輯器，打開 `appsscript.json`，用本專案 `apps-script/appsscript.json` 的內容取代，儲存。
5. 回到 `程式碼.gs`，頂部函式選單揀 `setupSheets` → 按 **執行**。
   - 第一次會要求授權：**審查權限** → 揀你的帳戶 → 如見到「Google 尚未驗證這個應用程式」，按 **進階** → **前往「…」（不安全）** → **允許**。這個程式是你自己的，所以 Google 會這樣提示。
   - 完成後，試算表會多了六個工作表：學生名單、關卡紀錄、錯誤紀錄、考試成績、總覽、設定。
   - 同時會自動產生一個隨機的 `SESSION_SECRET`（用來簽署學生的登入憑證），不用自己設定。
6. 填寫工作表：
   - **學生名單**：每位學生一行（電郵、班別、班號、姓名）。電郵要與學生登入的學校帳戶完全一樣。
   - **設定**：把示範行 `teacher@school.example` 改為你的學校電郵；有多位老師就加多幾行（類別填「老師」）。
   - 學生名單有改動後，在試算表選單按 **的士佬日記** → **更新總覽**。
7. 部署為網頁應用程式：Apps Script 右上角 **部署** → **新增部署作業** → 齒輪揀 **網頁應用程式**：
   - 說明：`v1`
   - **執行身分：我**
   - **誰可以存取：任何人**

     不用擔心：每個請求都要先通過 Google 登入驗證，程式才會讀寫資料；學生亦只可讀到自己的成績。
   - 按 **部署** → 複製「**網頁應用程式網址**」（以 `/exec` 結尾）。下面稱為「**Apps Script 網址**」。

> **以後修改 Code.gs**：要按 **部署** → **管理部署作業** → ✏️ 編輯 → 版本揀「**新版本**」→ **部署**，網址不變。只按儲存的話，學生用的仍是舊版本。

## 第 3 部分：建立 Google 登入（OAuth 用戶端 ID）

1. 打開 [Google Cloud Console](https://console.cloud.google.com)（用學校帳戶）。
2. 頂部專案選單 → **新增專案** → 名稱「的士佬日記」→ **建立**，然後確認頂部已切換到這個專案。
3. 左上選單 → **API 和服務** → **OAuth 同意畫面**（或 **Google Auth Platform**）→ **開始**：
   - 應用程式名稱：「的士佬日記」；使用者支援電郵：你的電郵
   - **目標對象**：
     - 如果你的學校帳戶屬 Google Workspace，而專案建立在學校機構之下 → 揀「**內部**」（只有學校帳戶可以登入，最簡單）。
     - 否則揀「**外部**」。完成後到「目標對象」按「**發布應用程式**」。我們只用最基本的登入資料（電郵、姓名），不需要 Google 審查。
   - 聯絡資料：你的電郵 → 同意政策 → **建立**。
4. **用戶端**（或 **憑證** → **建立憑證** → **OAuth 用戶端 ID**）：
   - 應用程式類型：**網頁應用程式**
   - 名稱：「的士佬日記網頁」
   - **已授權的 JavaScript 來源** → 新增：**`https://wychankelly-hub.github.io`**

     只填網域：**不要**加 `/taxi-python-game`，最後亦**不要**加 `/`。
   - 「已授權的重新導向 URI」：**留空**。
   - 按 **建立** → 複製「**用戶端 ID**」（以 `.apps.googleusercontent.com` 結尾）。
5. 回到 Apps Script → 齒輪 **專案設定** → **指令碼屬性** → **新增指令碼屬性**：
   - `CLIENT_ID` = 剛才的用戶端 ID
   - （可選）`ALLOWED_DOMAIN` = 學校電郵 `@` 後面的部分，例如 `school.edu.hk`。設定後只接受學校帳戶。
   - 確認已有 `SESSION_SECRET`（第 2 部分自動產生）→ **儲存指令碼屬性**。

## 第 4 部分：把兩個網址填入遊戲

1. 打開本專案 `public/js/config.js`，填入：

   ```js
   window.TSD_CONFIG = {
     googleClientId: '…你的用戶端 ID….apps.googleusercontent.com',
     appsScriptUrl: 'https://script.google.com/macros/s/…/exec',
   };
   ```

   兩個值都可以公開，不是密碼。也可以直接把兩個值告訴我，我代你填。
2. 上載到 GitHub（`main`），GitHub Actions 會自動測試及重新發佈（約一兩分鐘）。

## 第 5 部分：老師控制台

- 網址：**`https://wychankelly-hub.github.io/taxi-python-game/teacher.html`**。老師帳戶在遊戲首頁登入後，亦會見到「老師控制台」按鈕。
- 用你的學校帳戶登入。只有「設定」工作表內列為「老師」的電郵可以進入。
- 功能：

| 分頁 | 內容 |
| --- | --- |
| 全班進度 | 每位學生一行，24 關顏色格（灰：未玩、黃：1 星、淺綠：2 星、綠：3 星），加收工小測、考試最高分、最後上線 |
| 最常錯的題目 | 答錯次數最多的 10 題，及最多人選的錯誤選項 |
| 個別學生 | 點學生姓名：每關星數、錯誤紀錄、每次考試每題得分，並可為該生解鎖 |
| 解鎖 | 為全班解鎖全部關卡及考試模式（例如中六直接做考試模式）；學生下次開遊戲即生效 |

上面有班別及日期範圍篩選，適用於所有分頁。

## 第 6 部分：上線前用 iPhone 測試

用一位學生的學校帳戶，在 **iPhone Safari** 打開遊戲網址：

- [ ] 首頁出現「用 Google 登入」按鈕 → 揀學生帳戶 → 顯示「你好，〇〇〇！」
- [ ] 玩完一關 → 首頁顯示「成績已全部傳送」→ 試算表「關卡紀錄」多了一行
- [ ] 故意答錯一題 → 「錯誤紀錄」多了一行
- [ ] 開飛航模式玩一關 → 首頁顯示「待傳送 N 筆」→ 關閉飛航模式，再回首頁 → 變成「已全部傳送」，試算表沒有重複的行
- [ ] 關掉 Safari 再開 → 仍然登入（不用再揀帳戶）
- [ ] 用一個不在學生名單的帳戶登入 → 顯示「未有你的資料，請聯絡老師」
- [ ] 老師控制台見到該學生；按「為 中五 全班解鎖」→ 學生重開遊戲，全部關卡可玩

### 如果學生登入時被擋（學校 Google Workspace 管理員設定）

有些學校的 Workspace 會封鎖未經批准的第三方應用程式，學生會見到「已封鎖存取權」。請把以下資料交給學校的 IT 管理員：

- 管理控制台 → **安全性** → **存取權和資料控制** → **API 控制項** → **管理第三方應用程式存取權** → **設定新的應用程式** → 用 **OAuth 用戶端 ID** 搜尋 → 選擇 → 存取權設為「**信任**」。
- 只用基本範圍：`openid`、`email`、`profile`。

## 常見問題

| 情況 | 原因及解決方法 |
| --- | --- |
| 首頁沒有「用 Google 登入」 | `config.js` 兩個值未填好，或 GitHub Actions 未發佈完／失敗（看 **Actions** 分頁有沒有紅色交叉） |
| 更新後 iPhone 仍見舊版本 | GitHub Pages 有快取，等幾分鐘或在 Safari 重新載入 |
| 按登入後彈出「Error 400: origin_mismatch」或「The given origin is not allowed」 | 第 3 部分「已授權的 JavaScript 來源」不是 `https://wychankelly-hub.github.io`（檢查 https、拼寫；不要加 `/taxi-python-game` 或最後的 `/`）；改完要等幾分鐘才生效 |
| 登入後顯示「登入失敗」 | Apps Script 的 `CLIENT_ID` 與 `config.js` 不一樣；或改了 Code.gs 但未部署「新版本」 |
| 「請用學校的 Google 帳戶登入」 | 設定了 `ALLOWED_DOMAIN`，但用了其他帳戶 |
| 學生登入後顯示「未有你的資料」 | 學生名單的電郵與登入帳戶不一樣（留意大小寫以外的拼寫、空格） |
| 試算表沒有新紀錄 | 首頁看看「待傳送」數字：有網絡時會自動傳送；如一直不減，檢查 Apps Script 部署的「誰可以存取」是否「任何人」 |
| 老師控制台說「不是老師帳戶」 | 「設定」工作表加一行：類別「老師」、對象為該電郵 |
| 總覽某些格顯示錯誤 | 學生名單有改動後，按 **的士佬日記** → **更新總覽** |

## 安全及私隱

- 遊戲只取得學生的電郵及姓名，用來在學生名單找出班別、班號。
- 不會相信遊戲傳來的電郵：Apps Script 每次都向 Google 驗證登入權杖，之後的登入憑證由 `SESSION_SECRET` 簽署，學生無法冒充其他同學。
- 學生只能讀取自己的成績；全班資料只限老師帳戶。
- 試算表只存在你的 Google 雲端硬碟。
